Canopy needs two things: Canopy itself, and at least one engine for your agents to think with. Most people should install with Homebrew and use Claude Code; if you already run OpenCode with your own model provider, that works too, and you can mix both in one channel.

<CardGrid>
  <a class="guide-card" href="/canopy-site/getting-started/claude-code/">
    <Card title="Install with Homebrew (Apple Silicon)">
      Install Canopy and Claude Code with Homebrew in five minutes. Claude Code (recommended).
    </Card>
  </a>
  <a class="guide-card" href="/canopy-site/getting-started/claude-code/#tab-from-source-any-os">
    <Card title="Run from source (Intel, Linux, or Apple Silicon)">
      Clone and build Canopy locally with Elixir. Use Claude Code or OpenCode, or both.
    </Card>
  </a>
  <a class="guide-card" href="/canopy-site/getting-started/opencode/">
    <Card title="Use OpenCode">
      Start an OpenCode server with your own model provider and connect it to Canopy.
    </Card>
  </a>
</CardGrid>

All paths end with the same local Canopy workspace, repository, channel, and read-only first task. Configure another agent with either engine later in [Settings](/canopy-site/docs/settings/). After you finish, [try the demo](/canopy-site/docs/try-the-demo/) to see every feature at once.
