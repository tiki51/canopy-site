Canopy needs two things: Canopy itself, and at least one engine for your agents to think with—Claude Code, Codex, or OpenCode. Pick the guide for the engine you want to start with; you can add the others anytime and mix all three in the same channel.

<CardGrid>
  <a class="guide-card" href="/canopy-site/getting-started/claude-code/">
    <Card title="Use Claude Code">
      Run Anthropic models with your existing `claude` login (Homebrew or from source, in about five minutes).
    </Card>
  </a>
  <a class="guide-card" href="/canopy-site/getting-started/codex/">
    <Card title="Use Codex">
      Run OpenAI models with your existing `codex login` (ChatGPT plan or API key).
    </Card>
  </a>
  <a class="guide-card" href="/canopy-site/getting-started/opencode/">
    <Card title="Use OpenCode">
      Start an OpenCode server with your own model provider and connect it to Canopy.
    </Card>
  </a>
  <a class="guide-card" href="/canopy-site/getting-started/claude-code/#install-canopy">
    <Card title="Run from source (Intel, Linux, or Apple Silicon)">
      Clone and build Canopy locally with Elixir. Use Claude Code, Codex, OpenCode, or all three.
    </Card>
  </a>
</CardGrid>

Every path ends the same way: the first time you open Canopy, a short setup window checks your engines, picks a default engine, lets you choose a default model, and adds your first project. Then you open a channel and give an agent a read-only first task. Give an agent a different engine or model later on the [Agents](/canopy-site/docs/agents/) page. After you finish, [try the demo](/canopy-site/docs/try-the-demo/) to see every feature at once.
