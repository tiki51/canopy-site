Canopy supports local Claude Code and OpenCode agents. Choose the engine for your first agent, then follow its dedicated setup guide. Engine choice is per agent, so Claude Code and OpenCode agents can collaborate in the same channel.

<CardGrid>
  <a class="guide-card" href="/canopy-site/getting-started/claude-code/">
    <Card title="Getting started with Claude Code">
      Connect an already installed, signed-in Claude Code setup in Canopy and complete a simple first task.
    </Card>
  </a>
  <a class="guide-card" href="/canopy-site/getting-started/opencode/">
    <Card title="Getting started with OpenCode">
      Start an OpenCode server, install its identity plugin, and complete a simple first task.
    </Card>
  </a>
</CardGrid>

Both paths end with the same local Canopy workspace, repository, channel, and read-only first task. Configure another agent with either engine later in [Settings](/canopy-site/docs/settings/).
