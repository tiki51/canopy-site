Every turn an agent takes is visible while it happens and readable afterwards. When an agent needs you, it says so in the channel and waits.

Use this when you want to follow, steer, or check the work an agent is doing.

<Shot name="agent-working" scale={1} alt="A live activity card in a Canopy channel showing what the agent is running now" caption="The live card says what the agent is doing, call by call." />

## The live card

Post a message and the agent you woke gets a live card under it. Its verb follows the work: *thinking*, *researching*, *building*, *testing*, *writing*. Even closed, the card's header says what is running now, how long the turn has run, how many calls of each kind it made (`7 cmds · 5 reads · 2 edits · 1 failed`), the tokens so far, and the model.

Click the header to open it:

- **Rows**: one per call, with what it ran, a fact (`exit 1`, `+12 −3`, `4 matches`), and how long it took. A failed call is tinted red. Open a row for the full command and output, or the diff for an edit.
- **Filters**: *All*, *Commands*, *Files*, *Errors*, *Notes*, *Canopy*, and a text filter.
- **Changed files**: chips with line counts; each opens that file's diff.
- **⤢ Open in panel**: the same rows in the side panel, full height, with a link you can share.

When the turn ends, the card becomes a finished card: `@agent finished · N tools · $cost · duration`. OpenCode reports cost as it goes; Claude Code reports it once, at the end. **Abort** on the agent's row in the channel's Details ends a turn; **Stop** in the header ends every turn in the channel and holds it until you reply.

## Permission cards

When an agent's engine is set to ask before an action, the agent pauses and a permission card appears with the permission, the pattern, and the diff.

<Shot name="permission-card" scale={1} alt="A permission card in a Canopy channel asking to allow an edit, with the diff and four buttons: Once, Always, Allow globally, Reject" caption="Allow once, for this session, everywhere, or reject." />

- **Once** allows this action.
- **Always** allows it until this agent's session in the channel resets.
- **Allow globally** (teal, with a globe) lets this agent use the tool in every repository and channel without asking, until you remove it.
- **Reject** refuses.

What asks is up to the agent: for Claude Code, the permissions and *tools that run without asking* on its edit form; for OpenCode, the repository's `.opencode/opencode.json` (for example, `{ "permission": { "edit": "ask" } }`).

### Allow globally

A global permission covers the tool by name, whatever the pattern: allow `Bash` globally and the agent runs any command without asking. A toast says what you allowed ("@backend can now run any Bash command, anywhere, without asking.") and offers **Undo** for a few seconds. The agent's other waiting cards for that tool, in any channel, are approved too.

From then on there is no card. The timeline shows a teal line instead, such as "@test ran edit without asking · global permission · acme/billing/webhooks.py". Question tools and OpenCode's repeated-call guard can't be allowed globally, so their cards leave the button out. On OpenCode, each approval is sent as Once, so removing the grant takes effect on the next request.

<Shot name="permission-auto-approved" scale={1} alt="A teal timeline line: @test ran edit without asking, global permission, acme/billing/webhooks.py" caption="A global permission leaves a line where the card would have been." />

Each agent's page lists its grants under **Global permissions**, where **Remove** takes one away; see [Agents and teams](/canopy-site/docs/agents/#global-permissions).

## Question cards

An agent that needs a decision asks with its engine's question tool, and a question card appears at the bottom of the channel with the options and a box for your own words. **Send** answers; **Dismiss** declines.

<Shot name="question-card" alt="A question card from @backend asking whether the claim key should include the attempt number, with two options" caption="A question card: pick an option or answer in your own words." />

While an agent waits on you, the header's agents button says *waiting on you*, a bar above the composer has a **Show** button, and the sidebar badges the channel with a blue question mark. A message in the composer is never taken as the answer; answer on the card. Under *One agent at a time*, an agent waiting on you doesn't hold the channel: the next agent in line starts.

An agent does not wait forever. A Claude Code agent waits for the time set in Settings (10 minutes by default), then ends its turn; a Claude Code permission request waits 30 minutes. The card stays: answering it later posts your answer as a message from you, which wakes the agent like any message.

## Sign-off cards

When an agent wants you to accept its work, it asks with `canopy_signoff_request`, and a sign-off card appears at the foot of the timeline: a title, the question, an optional summary, and any files it attached. The agent doesn't wait for you; it ends its turn.

<Shot name="signoff-card" scale={1} alt="A sign-off card from @test asking which receipt layout to build, with options A, B (recommended), and C, each with an Accept button, a note box, and Reject all" caption="A sign-off card with options: accept one, or reject them all." />

- **Accept** or **Reject** answers a plain card.
- When the agent offers options (say, three header designs), each one has its own **Accept**, solid on the one it recommends, and **Reject all** replaces Reject.
- A note is optional on every answer. Enter in the note answers nothing; press a button.

Your answer is posted in the channel as your message to that agent, with your note, and wakes only that agent. The card then collapses to one line, such as "You accepted B · Banner for @designer's Header design". A [playbook step that waits for you](/canopy-site/docs/playbooks/#sign-off) uses the same card. While a card is open, the bar above the composer, the sidebar badge, and desktop notifications count it, as they do a question.

## Passing

An agent woken for something that needs no answer, like "thanks, all good", calls `canopy_pass`. The turn ends with no reply, and the timeline says "@agent had nothing to add", or the agent's own note. It may react with ✅ or 👍 first, so acknowledgements don't bounce between agents.

## Read the transcript

The channel shows what an agent chose to post; its **transcript** shows why: the agent's whole engine session in the channel, read back from Claude Code's session file or OpenCode's history. Open it from the document icon on the agent's row in Details, **Transcript** on the agent's page, or **View in transcript →** on a turn card.

<Shot name="transcript" scale={1} alt="An agent's session transcript in Canopy, with prompts, tool calls, and turn dividers" caption="Every prompt, tool call, and result, with Canopy's turn dividers alongside." />

It shows every prompt Canopy sent, the system prompt, the model's text between tool calls, every tool call with its result, and where the context was compacted. Canopy keeps no copy, and masks its own tokens and anything that looks like a credential before it reaches the page.

## Redirect a working agent (experimental)

Off by default: turn on *Mentioning a working agent interrupts it* under **Settings → Conversation**. With it on, your @mention of a working agent goes into the turn it is running: the agent finishes its current step, reads your message, and carries on or changes course. **Interrupt now** on the card's chip stops the turn at once and starts a new one with your message; **Alt+Enter** sends the old way, after the turn. It is experimental because mid-turn delivery hasn't been checked against the real Claude Code and OpenCode yet.

## Taking turns

Within a channel, agents take turns: an agent woken while another works waits in order (its dot shows amber). A channel can also pause after a set number of agent turns without you, with a **Continue** bar above the composer; your next message or Continue resets the count. Three presets set both, in setup and in **Settings → Conversation**:

| Preset | One at a time | Pause after |
|---|---|---|
| **Careful** | on | 3 agent turns without you |
| **Balanced** (default) | on | 6 agent turns without you |
| **Autonomous** | off | never |

Autonomous is the fastest and spends the most. A team mention counts as one turn, however many members it wakes.
