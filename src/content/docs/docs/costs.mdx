Every finished turn reports what it spent. Claude Code and OpenCode report their costs directly; Codex turns are estimated from tokens at OpenAI's API list prices and marked with **≈** (`≈$1.03`, with the split between reported and estimated dollars on hover). The Costs page adds it up, and you can cap spend per turn and per channel, in dollars, before the work starts.

Use this when you need to review spend or put a firm limit on a channel.

## Inspect spend

Open **Costs** from the banknotes icon in the rail:

- **Today, last 7 days, all time**, with turn and tool-call counts, a bar per day for the last 14 days, and **By engine** (Claude Code, Codex, OpenCode) beside it. When any row includes a Codex estimate, a footnote notes that on a ChatGPT plan you pay the plan, not these estimated API list prices.
- **Where the tokens go**: model calls, cost per turn, context per call, cache hit rate, and the turns that bought nothing.
- **By agent, channel, model, and trigger**: *trigger* is what woke the agent (your messages, agent messages, delegations, handoffs, schedules).
- **Costliest turns**, and every **channel spend limit**, red when reached.

Turns that errored, or ran on a provider that reports nothing, count as zero, so treat the totals as a floor. Context is most of the bill: Canopy keeps it small by compacting sessions, sending agents only what is new, and keeping the shared prompt prefix cacheable.

## Ask for an audit

Pick an agent in the **Auditor** dropdown, optionally type a focus, and press *Ask @agent to audit*. Canopy opens a DM with that agent and points it at `canopy_costs_report`; it replies with ranked recommendations. The auditor can't change models, limits, or settings: it proposes and you decide. `@finops` is built for the job, but any agent will do.

## Five brakes

From gentlest to firmest:

1. **Model choice.** Change the default model first, since it moves every agent without its own; then override the few that need a stronger or cheaper one.
2. **One agent at a time** and the **optional pause** (Settings → Conversation).
3. **A spend cap per turn** (Settings → Claude Code, Claude Code agents only), passed as `--max-budget-usd`. Codex has no per-turn cap.
4. **Channel spend limits**, set on the new-channel form or under **Spend** in the channel's Details (Codex estimates count towards the limit). Once a channel reaches its limit, later wake-ups are dropped and a red bar sits above the composer until you raise it. A turn already in flight finishes, so a channel can overshoot by one turn. Only you can change a limit.
5. **The billing hold**, which Canopy engages itself when an engine reports an empty balance, quota, or usage limit. See [Settings](/canopy-site/docs/settings/#billing-holds).

<Shot name="spend-limit-reached" scale={1} alt="A Canopy channel at its spend limit, with a red bar above the composer" caption="At the limit, the channel goes quiet until you raise it." />

If spend looks wrong, compare the period you picked and the model in *By model*. Claude Code costs dropped sharply after an upgrade? Earlier versions recorded Claude Code's running session total as each turn's cost; Canopy now records each turn's own cost and corrected past turns once.
