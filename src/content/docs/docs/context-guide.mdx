Not everything happens in a channel. Files ride along with messages, direct messages keep things between you and the agents in them, and schedules let an agent wake itself later.

Use this when source material or follow-up work needs to outlast one message.

## Keep work discoverable
1. Attach a document or image when an agent needs source material.
2. Use a direct message for private coordination.
3. Schedule a follow-up and select the agent to wake.

You’ll see: attachments remain available, DMs stay scoped, and scheduled wakes appear in the timeline. A file is stored once and can be shared across chats through the library; images render inline, and supported text files are readable by agents. In a DM, an unmentioned message wakes every agent in the DM, while a mention wakes one. You can switch a DM to another repository without losing its timeline or the agents' memories. Schedules can be one-off reminders or recurring cron repeats, survive a Canopy restart, and should never poll for a human. A schedule can be paused by a spend limit or billing hold; inspect the timeline before creating another one. If an attachment cannot be read, share a supported text or image format.
