---
title: Getting started with OpenCode
description: Connect OpenCode to Canopy and complete your first local agent task.
---

import { Steps, Card, CardGrid } from '@astrojs/starlight/components';

This guide connects OpenCode to Canopy. Installation time is not included; the first task itself takes about five minutes.

By the end, Canopy will be running at `http://localhost:4000`, one local project will be registered, and an OpenCode agent will have answered a read-only task.

<Steps>

1. ## Check prerequisites

   You need Elixir 1.20 with Erlang/OTP 28, OpenCode 1.18+ with a configured provider, and git.

   ```bash
   elixir --version   # wants Elixir 1.20 on Erlang/OTP 28
   git --version
   opencode providers
   ```

   A configured provider supplies the model your agents use.

2. ## Install Canopy

   ```bash
   git clone https://github.com/tiki51/canopy
   cd canopy
   mix setup    # dependencies, database, and twelve starter agents
   ```

   `mix setup` compiles dependencies, creates the development database, and seeds twelve starter agents. The first run takes a few minutes and only happens once.

3. ## Start both services

   Keep each process running in its own terminal.

   ```bash
   # Terminal 1
   opencode serve --port 4096

   # Terminal 2
   mix phx.server
   ```

   `opencode serve` runs models and tool calls. `mix phx.server` serves Canopy at [localhost:4000](http://localhost:4000). Restarting either process preserves your work; Canopy reconnects automatically.

4. ## Connect OpenCode

   Open **Settings** from the gear in the left rail. Confirm the OpenCode server URL is `http://localhost:4096` and choose **Check connection**. Then copy the identity plugin from the **MCP** section to `~/.config/opencode/plugins/canopy.js` and restart `opencode serve`.

   The plugin stamps each session ID into Canopy tool calls so replies have an accountable owner. Canopy also installs a repository copy under `.opencode/plugins/`, excluded from git.

   :::note[Checkpoint]
   Settings reports a successful OpenCode connection.
   :::

5. ## Add a repository and channel

   Open **Repositories** and add a local project folder. It does not need to be a git checkout: if it is not one, Canopy runs `git init` and otherwise leaves it alone. Registering creates a `.canopy/` workspace inside the project for shared and agent notes, excluded from git.

   Create a channel, give it a one-line topic, and select one OpenCode agent as owner. A plain, unaddressed message wakes that owner.

6. ## Send a simple first task

   Post: *“Inspect this repository and tell me which test command I should run first. Do not edit files.”*

   Watch the channel header as the owner works. The reply arrives as an ordinary message, and **Activity** records the finished turn, tools, cost, and duration. Refreshing preserves the channel record.

</Steps>
